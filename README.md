# Btier

مرحبًا بك في Btier، المشروع الذي يهدف إلى توفير أفضل الحلول عبر الإنترنت.

## المستندات

هذا المستند يوفر معلومات شاملة حول كيفية استخدام المشروع وتثبيته.

### التثبيت

لتثبيت Btier، يرجى اتباع الخطوات التالية:

1. تأكد من أن لديك Python 3 مثبتًا.
2. قم بتنزيل أو استنساخ المستودع:
    ```bash
    git clone https://github.com/amineouichtati03-cmyk/Btier.git
    ```
3. انتقل إلى الدليل:
    ```bash
    cd Btier
    ```
4. قم بتثبيت المتطلبات:
    ```bash
    pip install -r requirements.txt
    ```

### الاستخدام

بعد التثبيت، يمكنك تشغيل المشروع باستخدام الأمر:
```bash
python main.py
```
